# Oracle Motion app icon

The Oracle app tile, like every Oracle app: a rounded square in the app's colour (`#8a3ffc`) with the
Oracle four-pointed star and the letters "Mo".

Drawn by `Oracle-suite/tools/make_app_icon.py`, which writes the SVGs, the 1024 px PNG, the `.ico`, the
`.icns` and the `hicolor/` sizes.
