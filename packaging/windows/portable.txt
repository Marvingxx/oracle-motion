Oracle Motion portable mode

While this file sits next to oracle-motion.exe, Oracle Motion keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the Oracle MotionData folder beside it instead of
%APPDATA%\Oracle Motion. Copy the whole folder to move Oracle Motion with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Oracle Motion unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Oracle Motion) instead.
If Oracle MotionData can't be written (for example on a read-only drive), Oracle Motion logs a
warning and uses %APPDATA%\Oracle Motion instead.
